## 本轮修正的判据缺陷（停工诊断 15:24Z 打回项 ②）

旧 `panel_point(d)` 返回写死的比例坐标 `(0.437w, 0.685h)`，点空也照跑；`case3` 只断言
「没有 commit」，于是**面板从未打开也能判 pass**——判据不可证伪。本版改为：

1. `find_phrase_key(d)` 以 **IME 窗口高度变化**为命中证据（快捷短语面板开在键盘上方、键盘仍可见，
   窗口只会变高），逐行扫描工具栏，命中一次才返回坐标；
2. `case3` 每轮都复核 `panel_opened`，**任一轮打不开面板即判 fail**，不再存在「没测也算过」；
3. 实测命中点 `(453, 1582)` = `(0.420w, dy=160)`，IME 高度 `918→1811`。
