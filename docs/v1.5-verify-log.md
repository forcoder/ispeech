编译过程中抓到并修掉一处**真实编译错误**（离线脚本查不出的那类）：

| 错误 | 原因 | 修正 |
|---|---|---|
| `Unresolved reference: minWidth` / `minHeight`（`QuickPhrasePanel.kt:449/633`） | `minWidth/minHeight` 是 `TextView` 的属性；换成 `ImageView` 后不存在，`View` 上是 `minimumWidth/minimumHeight` | 改为 `minimumWidth` / `minimumHeight` |

```bash

# → 首次失败：INSTALL_FAILED_UPDATE_INCOMPATIBLE（模拟器上旧包是另一套签名）
```

**无 `FATAL` / `AndroidRuntime`**。

## 3. 修复 ② 短语搜索框获得输入焦点

点工具栏「短语」→ 面板打开，搜索框**整圈描出主题色边框**（`state_focused` 命中），
说明输入焦点确实落在搜索框上（改前 `isFocusable=false`，不会有这圈描边）。

- 实现：`QuickPhrasePanel.searchRow` 改为可聚焦容器 + `searchBoxBackground()` 的
  `state_focused` 描边；服务在 `openPanel(Panel.QUICK_PHRASE)` 里调 `requestSearchFocus()`。
- 不回退原有行为：软键盘字母键仍经 `handleSoftKey → setPanelKeyword` 进面板关键词（不弹系统键盘）。

## 4. 修复 ④ 短语搜索复用键盘「中/英」输入状态

| 键盘态 | 面板搜索框右侧徽标 | 判定 |
|---|---|---|
| 中文态 | 「**中**」主题色、「英」灰 | ✅ 与键盘左下角键一致 |
| 英文态 | 「中」灰、「**英**」主题色 | ✅ 与键盘左下角键一致 |

- 实现：面板新增 `setInputLanguage(english)`，服务在 `openPanel()` 与 `toggleMode()` 两处推送
  **同一个 `mode` 字段**（键盘「中/英」键用的就是它），面板不另存语言状态、无磁盘 IO。
- 切中英时键盘键面与面板徽标**同帧同步翻转**，即「复用同一状态源」而非各存一份。

## 5. 修复 ① 语音输入

| 步骤 | 观测 | 判定 |
|---|---|---|
| `pm grant com.ispeech.ime android.permission.RECORD_AUDIO` 后点工具栏 🎤 | 候选条显示 **"Listening…"**；系统状态栏出现**绿色麦克风指示**；短语面板自动关闭 | ✅ 识别器真的起来了、麦克风真的在被采集 |
| 5 秒后 | 候选条变为 **"Voice recognition failed"**，麦克风指示消失，输入法无崩溃、可继续打字 | ✅ 状态机能优雅收尾，不卡在「聆听中」 |

期间识别服务侧日志出现 `NetworkSpeechRecognizer` 的异常堆栈——这是 Google 识别服务
在**模拟器无网络**时做云端识别失败，属预期；**能走到这一步即证明录音链路已经打通**
（改前 `stop()` 不销毁识别器，麦克风被占，下一次点击直接撞 `ERROR_RECOGNIZER_BUSY`）。

> 未验证项（诚实声明）：**真实语音转文字的准确率**在模拟器上无法验证（无麦克风输入、
> 无网络 ASR）。这条只能在真机上验收。

> 语音输入的接线、行为矩阵与复刻义务清单见 `docs/voice-input.md`。
