# 搜狗五笔功能对照表（智语 iSpeech v1.5）

本表用于说明「复刻搜狗五笔」的进度：哪些功能已经实现、与搜狗的行为差异、以及为什么某些功能暂时没做。
状态以 `app/src/main/java/com/ispeech/` 下的实际代码为准。

## 输入方案

| 功能 | 搜狗五笔 | 智语 v1.5 | 说明 / 差异 |
| --- | --- | --- | --- |
| 五笔 86 | 支持 | 支持 | 内置 `assets/wubi86.dict`，支持单字 / 词组 / 简码；`z` 作通配符 |
| 五笔 98 | 支持 | 未实现 | 需要 98 版码表数据（Roadmap） |
| 拼音混输 | 支持 | 支持 | `assets/pinyin86.dict`（71097 行：单字 15511 / 词组 55575，含 26413 条注音补全）+ `PinyinEngine`（全拼 / 简拼 / 前缀三层），设置页可开关；作为兜底档位排在五笔之后 |
| 模糊音 / 双拼 | 支持 | 部分 | 模糊音已实现（z=zh、c=ch、s=sh、n=l、an=ang、en=eng、in=ing，设置页开关）；双拼未实现 |
| 笔画 / 手写 / 语音 | 支持 | 部分 | 手写 / 笔画未实现（需手写识别 SDK，Roadmap）；**语音输入已实现**，详见「效率工具 → 语音输入」行与 `docs/voice-input.md` |
| 云输入（云端候选） | 支持 | 部分 | 已有 csBaby 远端关键词规则与 AI 回复，但无「云端补全词」 |
| 简繁切换 | 支持 | 支持 | `HanConversion` + `assets/han_s2t.txt` / `han_t2s.txt`（字符级，简繁词汇不消歧）；设置页「繁体输出」开关，真机实测 `983`→「說」 |

| 数字页 | 支持 | 支持 | 1-0 + 常用符号，数字键长按给全角 / 带圈 / 带括号形态 |

| 表情 / emoji | 支持 | 支持 | 8 个分类（常用 / 手势 / 情感 / 动物 / 食物 / 活动 / 符号 / 旅行），每类一屏 |

| 按键预览 / 长按候选 | 支持 | 支持 | 按下放大气泡（Shift 键除外，其键面已是矢量箭头图标，不再弹旧字形）；长按带 alt 的键弹出候选气泡；字母页 `,` `。` 键长按可出中文常用标点候选 |
| 图标 | 候选翻页箭头有独立图标文件 | 支持 | 已复刻搜狗候选翻页箭头（`Skins/*/oh_pageup_off1.png`、`oh_pagedown_off1.png` → `ic_page_prev/next.xml`），并补齐本 App 原先用字符当图标的 6 处（`‹ 🔍 ✕ ★ ☆ ⚙` → `ic_back/ic_search/ic_close/ic_star/ic_star_filled/ic_settings_gear.xml`）。**搜狗 macOS 版没有软键盘，因此不存在按键/工具栏图标文件**——`符 / ☺ / 短语 / AI` 等入口在两版里都是文字，保持文字不失真。溯源与映射见 `docs/icon-replication.md` |
| 长按连删 | 支持 | 支持 | 长按退格 380ms 后开始连删，先慢后快 |
| 键盘高度 / 皮肤 | 支持 | 部分 | 高度三档（46 / 52 / 58dp）+ 震动开关；皮肤仅主题色，无独立皮肤包 |
| 滑行输入 / 手势翻页 | 支持 | 部分 | 翻页用页码条 / 九宫格 `#`·`☺` 直达页 / 硬件 `-` `=`；工具栏横向滚动兜底；无滑行输入 |

## 后续可做（Roadmap）

v1.5 已交付（原 Roadmap 第 1、2、3、4、6、7、8 项）：颜文字 / 更多符号页、输入统计、简繁转换、
拼音混输 + 模糊音、九宫格（T9）、**语音输入（系统 SpeechRecognizer 的候选条版）**。
词库侧已交付：**手动自造词（候选条长按）**、**用户词库导入 / 导出**、用户词库按输入模式分库（`wb` / `cn`）。
剩下的按实现代价从低到高：

1. **手势翻页 / 键盘左滑删除**：`SoftKeyboardView` 内加 `onTouchEvent` 手势识别
2. **分类词库（细胞词库）**：对齐搜狗 `InitializeWithMode:CateDictArray:` / `pfnAddDict` /
   `pfnDelDict`，支持本地文本词库的安装、启停与排序
3. **九宫格音节切分**：现在靠字母组合枚举（`T9_PATTERN_LIMIT = 192`），>6 位数字候选会变少
4. **双拼**：需要双拼键位映射表（拼音码表已就位）
5. **五笔 98**：需要 98 版码表数据
6. **手写 / 笔画**：需要手写识别 SDK（语音输入 v1.5 已交付，接线与差异见 `docs/voice-input.md`）
7. **云词库 / 词频云同步**：需要后端配合（csBaby 侧新增词库接口）
