# 符号键盘：与搜狗五笔的布局对齐

## 结论先行

- 本轮**只做了有取证支持的那一处改动**：字母页底行按键顺序，改成与搜狗截图完全一致的 `符 / 123 / ，/ 空格 / 。/ 中英 / 换行`。
- 搜狗**符号面板本体**（哪些分类页、每页几行几列）没能取到证据，因此没有凭印象去改。原因见「取证过程」。

## 取证过程

### 1. 静态：拆搜狗 APK（94MB，`com.sohu.inputmethod.sogou`）

| 资源 | 内容 | 对我们的意义 |
| --- | --- | --- |
| `assets/exp_symbol` | XML，7 个 `<Category>`：开心 63 / 生气 58 / 伤心 52 / 惊讶 39 / 无语 38 / 亲亲 52 / 怀旧 46 条 `(*^ω^*)` 类颜文字 | 这是**颜文字**表，不是符号面板；我们已有等价实现 |
| `assets/keyboard/*/cn_symbol_digit_26.ini` | 26 键模式下符号键替换回车键的位置定义（`ROW4` / `Key_Return_Symbol` 等） | 描述的是**字母页底行几何**，印证了底行顺序 |
| `resources.arsc` / `classes*.dex` | 未搜到「中文符号 / 英文符号 / 数学符号」等分类名，也未搜到 `①②③`、`±×÷≠≤≥` 这类符号串 | 符号主面板数据不在这些明文资源里（可能是服务端下发或加密资源），**静态取不到** |

工具现状：本机没有 jadx / apktool / dexdump，REA 的 MCP 工具在本会话未连接，因此没有做方法级反编译。

### 2. 运行时：在真机（华为 ALN-AL00）上抓搜狗键盘

截屏取证到搜狗五笔字母页底行：

```
符 | 123 | ， | 空格（含 🎤） | 。 | 中/英 | 换行
```

这和我们的实现不一致（我们原本是 `符 | 中/英 | ， | 空格 | 。 | 123 | 换行`），已按证据改齐。

至于符号面板本身：反复用 `adb shell input tap` 点「符」键，点击坐标始终落偏（多次命中字母键、把 `z` 打进了输入框），`KEYCODE_SYM` 触发的是系统「选择输入法」弹窗，`uiautomator dump` 也拿不到键盘按键（搜狗按键是 Canvas 自绘，无节点）。**没有可靠手段把符号面板翻页截下来**，所以这部分没有动。

## 本轮改动

`app/src/main/java/com/ispeech/input/keyboard/KeyboardLayouts.kt`：字母页底行按键顺序按搜狗截图重排（仅调整顺序，权重与样式不变）。

## 现状与后续

我们的符号页目前是：

- `符号1`：中文标点两行 + 光标左右移动键 + 底行 `123 / ABC / 空格 / ↵`
- `符号2`：四则运算 / 数学 / 货币 / 序号 三行 + 底行
- 追加 `T9Layouts.moreSymbolPages()`：数学 / 箭头 / 货币 / 单位 / 希腊 / 线框

要对齐搜狗，还缺一份**符号面板的实拍证据**。最省事的办法是：在手机上打开搜狗 → 点「符」→ 手动翻一页截一张图（中文 / 数学 / 特殊 各一张）。拿到图后可以照着把分类条和网格改掉。
