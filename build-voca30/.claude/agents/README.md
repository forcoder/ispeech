# iSpeech 专用智能体配置

## 智能体映射

| iSpeech 需求 | 对应智能体 | 说明 |
|--------------|------------|------|
| Android 输入法开发 | Mobile App Builder | 专注于原生 iOS/Android 开发 |
| 多语言支持 | i18n Engineer | 专注于国际化、多语言适配 |
| 架构设计 | Software Architect | 专注于软件架构和性能优化 |
| 性能基准测试 | Performance Benchmarker | 专注于性能测试和基准测试 |
| 测试自动化 | Test Automation Engineer | 专注于测试自动化和 CI/CD 集成 |

## 使用示例

- `Mobile App Builder`: "帮我优化 IME 服务的启动性能"
- `i18n Engineer`: "实现拼音混输和五笔混合输入功能"
- `Software Architect`: "设计民宿词库集成方案"
- `Performance Benchmarker`: "测试候选词排序性能"
- `Test Automation Engineer`: "为 QuickPhraseEngine 创建自动化测试"

## 智能体调用

在 Claude Code 会话中，可以直接引用智能体名称：

```
使用 Mobile App Builder 帮我分析 IME 生命周期管理问题
```

```
激活 i18n Engineer 并帮助我实现多语言支持
```
