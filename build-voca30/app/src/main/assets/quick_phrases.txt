# 快捷短语 / 快速应用 规则表（Tab 分隔，# 开头为注释）
# 字段: trigger <TAB> label <TAB> content [<TAB> mode] [<TAB> weight] [<TAB> kind]
#   trigger : 触发码（小写 a-z，1-4 位，便于在 IME 缓冲区输入）
#   label   : 候选面板显示的简称
#   content : 选中后真正贴入输入框的详细内容（快速应用）
#   mode    : exact | prefix | contains | regex （默认 prefix）
#   weight  : 权重，越大越靠前（默认 100）
#   kind    : p=短语 a=应用（默认 content==label 时 p，否则 a）
hi	你好问候	你好，请问有什么可以帮您？	exact	120	a
thx	感谢语	感谢您的支持与理解，祝您生活愉快！	prefix	110	a
addr	家庭住址	广东省广州市天河区五山路483号	prefix	100	a
tel	联系电话	020-12345678	prefix	100	a
em	邮箱地址	support@example.com	prefix	100	a
slogan	品牌口号	技术驱动，服务至上，让输入更高效	prefix	80	a
eof	结尾签名	此致\n敬礼	exact	70	a
